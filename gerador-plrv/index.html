Gerador de arquivo .PLRV

Gere um arquivo binário .PLRV usando o modelo Nicola como base.

Dados do jogador

Preencha o nome que aparece no cadastro e o nome curto exibido no jogo.

Importante

Este primeiro gerador exporta um arquivo binário .PLRV de 124 bytes, alterando os dois campos de nome do modelo Nicola e preservando os demais bytes originais. Ele ainda não altera atributos, posição, nacionalidade ou clube: o mapa desses campos precisa ser confirmado para não gerar um arquivo inválido.

O download não é JSON. O nome do arquivo gerado será JOGADOR_PLRV.PLRV.
